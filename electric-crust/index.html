The pitch

My debut title is a retro side-scrolling space shooter. Pilot Ace blasts through a 15-stage campaign across asteroid fields, neon nebulas, and enemy fleets, delivering pizza for Chef Rex across the galaxy. Tiered boss battles, warp mechanics, and a climbing rank system keep every run fresh.

iOS Android Steam Xbox PlayStation

// What to expect

Features

15-stage campaign. A full run from the outer asteroid fields to the neon nebulas at the galaxy's core.

Tiered boss battles. Escalating encounters that test everything you have learned by that point in the run.

Warp mechanics. Reposition fast, dodge incoming fire, and open windows for a counterattack.

A climbing rank system. Every run is scored, so there is always a reason to go one more round.
