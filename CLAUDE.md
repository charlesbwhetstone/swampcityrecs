## Answers from Viper

Viper answers the daily email's decisions (D1, D2...) and tasks (T1, T2...) by replying to it. The ops reply reader
files each answer for this project in `~/dev/ops/daily/answers/swampcityrecs.md`. At the start of every session, read that file
if it exists. For each answer not acted on yet: treat it as Viper's own decision; carry it out under this project's
normal rules (branches, reviews, and Viper's commit and merge approvals still apply); and record the decision or the
task's new state in the project's notes (docs/STATUS.md), so it drops off the daily email.
